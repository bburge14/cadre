Forgot your password?

Can't be recovered — it's hashed one-way and never stored in plaintext, anywhere. It can only be reset from a terminal with access to this machine (not from this page — that's deliberate, so a reset can't be triggered by anyone who can merely reach this login screen):

./linux/reset-admin.sh
(or macos/reset-admin.sh / windows\reset-admin.bat)

Deletes only the admin account — sessions, agent stacks, skills, and settings are untouched. Reload this page afterward and you'll land on account setup instead of here.
