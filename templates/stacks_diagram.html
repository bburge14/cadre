Each line is a permission: "this one is allowed to call that one." Click any agent to change who it can call.

Coordinator is your actual conversation — you, talking to the top-level session. Lines from it show every agent you can delegate to directly, just by asking for that kind of work.

Lines between two agents mean the first can call the second itself, without you asking for it by name — e.g. if debug-qa can call researcher, it can go look something up on its own mid-task instead of stalling.

Why restrict it: keeps an agent from wandering outside its lane (a writer probably shouldn't be able to spawn a python-engineer), and keeps delegation chains short and predictable instead of every agent being able to call every other agent.

There's no wrong answer here — start permissive (or use a preset's defaults) and tighten it only if an agent is calling something it shouldn't.

The small colored circle on each node is which AI actually does that agent's work (set via "primary AI for this agent's actual work" on its edit page) — Claude by default, or another provider if you've delegated that agent's work elsewhere.
